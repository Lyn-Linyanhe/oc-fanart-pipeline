# 创作者工作台使用说明（2026-10 优化版）

工作台：`python scripts/studio_app.py` → http://127.0.0.1:8788/ （仅本机）。
打开默认停在**作品审阅**，一页一组：左边灵感原图，右边我们的成图，← / → 或底部缩略图翻页。

## 日常循环

1. **审阅**：逐张看左右对照，可用 `1` 通过 / `2` 待复核 / `3` 垃圾篓（输入框聚焦时快捷键自动失效）。垃圾篓只是标记，原文件不删；`恢复未审` 可拉回，`撤销` 回退上一次审核操作（含备注）。
2. **备注**：每张可写审核备注（如“保留笑容，修整手指”），随审核记录保存在本机 `review.json`。
3. **改图**：右侧编辑区选「重新创作」（身份+灵感重画）或「以当前成图精修」（当前成图作第一张底图）。提示词**整段可改，改什么发什么**；删除 Negative 段落即真的不发负向词。
4. **提交**：一次一张，排队后可在「任务」页看进度；失败不自动重试（可能已扣费），先核对再手动重发。原版本永远保留，新版通过「关联版本」跳转，也可切换左栏看「上一版本」。
5. **新建创作**：从素材库选其他作品的灵感图（可按“模型初筛可用/未筛选”过滤），整理出完整提示词后生成第一张。

## 草稿与安全

- 提示词、比例、质量的修改即改即存（本机 `_results/drafts.json` + 浏览器 localStorage 双份），翻页、刷新、轮询都不会冲掉正在输入的内容。
- 模板可把当前提示词+参数存起来复用；应用模板会替换草稿，请再检查参考图职责。
- 每次提交会把完整提示词、参考图副本（含 sha256）、模型/尺寸/质量、父版本和所用线路快照落盘，之后作品页显示的就是**当时实际发送的内容**，不再靠拼装猜测。

## 诚实显示的限制

- 历史旧图没有完整提示词日志时，页面明确写“重建草稿，不代表当时的请求”，参数列显示「未记录」；不会伪造历史。
- 请求尺寸 ≠ 实际输出：作品页显示 Pillow 读出的真实像素（上游可能改写尺寸）。
- 已识别为宽图拆分组（split_wide）的灵感图禁止只发半张，服务端直接拒绝；组图完整使用待后续支持。
- 精修是软参考编辑（GPT Image 非 ControlNet），仍可能改动细节；不承诺蒙版级局部修改。
- 质量默认 high；价格以供应商账单为准，界面不做成本承诺。

## 本机依赖

- 生图凭据：`~/.zcode/image-edit.local.json`（active profile，base+key 成对）；工作台只显示 profile 名，不回显 key。
- 审核/草稿/模板/任务快照：桌面库（`<desktop-library>`）`_results/` 下 `review.json`、`drafts.json`、`presets.json`、`jobs.json`，均为原子写入。
- 服务重启时，排队/进行中的任务标记为「已中断」并保留快照，不自动重发；已写出的成图仍会进作品列表，并提示核对账单。

## 测试

`tests/test_studio.py` + `tests/studio_fixture.py` 是完全离线的隔离环境（临时素材库、假凭据、mock 上游）：

```bash
py -3.13 -m unittest discover -s tests -p "test_*.py"
```

覆盖：提示词原样发送与负向词删除、multipart 顺序与 MIME、重复提交去重、参考图冻结、失败不重试与 key 脱敏、重启不重发、审核撤销、宽图组拦截、越界路径拒绝、持久化失败不提交。
